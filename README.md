개인정보처리방침

서비스명: Guide Deck
시행일: 2026년 8월 28일

Guide Deck(이하 "본 서비스")은 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 본 서비스가 어떤 정보를 수집하고, 어떻게 이용·보관·제공하는지를 설명합니다.

1. 수집하는 개인정보 항목

1-1. 로그인 시 수집되는 정보
본 서비스는 Google 계정 로그인(Google Sign-In)만을 지원합니다. 로그인 시 Google로부터 다음 정보를 제공받습니다.

이메일 주소
기본 프로필 정보(이름, 프로필 사진)
고유 사용자 식별자(Firebase Authentication UID)

본 서비스는 이용자의 Google 계정 비밀번호를 수집하거나 저장하지 않습니다.

1-2. 이용자가 직접 입력하는 정보

닉네임
목표(goal) 및 현재 상황(current status) 텍스트
관심 카테고리
댓글 내용
기사 메모

1-3. 서비스 이용 과정에서 생성되는 정보

저장(북마크)한 기사 정보
읽은 기사 기록(7일 후 자동 삭제)
생성된 브리핑 및 인사이트 기록
커뮤니티 활동 기록(도움이 됐어요 표시, 인사이트 점수, 신고 내역, 차단 목록)
알림 설정값 및 앱 설정값(기기 내 저장)

2. 수집하지 않는 정보

본 서비스는 다음 정보를 수집하지 않습니다.

위치 정보
연락처, 통화 기록, 문자 메시지
사진, 카메라, 마이크
기기 저장소 내 파일
광고 식별자
사용자 행동 분석 데이터 및 자동 수집되는 크래시 로그

본 서비스에는 분석 도구(Analytics), 크래시 리포팅 도구, 광고 SDK가 포함되어 있지 않습니다.

3. 개인정보의 이용 목적

수집한 정보는 다음 목적으로만 이용합니다.

회원 식별 및 로그인 유지
이용자의 목표와 현재 상황에 맞춘 뉴스 브리핑 생성 및 제공
기사 저장, 메모, 알림 등 개인화 기능 제공
커뮤니티(댓글, 도움이 됐어요, 신고, 차단) 기능 운영
서비스 운영 및 이용자 문의 대응

4. 제3자 서비스로의 정보 전송

본 서비스는 기능 제공을 위해 다음 외부 서비스를 이용하며, 각 서비스로 전송되는 정보는 아래와 같습니다.

4-1. Anthropic (Claude API) — 중요
브리핑 생성, 기사 관련성 판단, 검색 키워드 생성, 기사 제목 번역을 위해 Anthropic의 Claude API로 이용자가 입력한 목표(goal) 및 현재 상황(current status) 원문이 기사 내용과 함께 전송됩니다.

이용자의 이름, 이메일 주소, 계정 식별자는 전송되지 않습니다.

목표와 현재 상황 입력란에는 민감한 개인정보(주민등록번호, 연락처, 주소, 건강 정보, 금융 정보 등)를 입력하지 않으시기를 권장합니다.

Anthropic의 개인정보 처리에 관한 사항은 Anthropic의 개인정보처리방침을 참고하시기 바랍니다.

4-2. Google (Firebase)

Firebase Authentication: 로그인 및 계정 인증
Cloud Firestore: 이용자 데이터 저장

Google의 개인정보 처리에 관한 사항은 Google 개인정보처리방침을 참고하시기 바랍니다.

4-3. 뉴스 제공 서비스
기사 검색을 위해 다음 서비스를 이용합니다. 이들 서비스에는 AI가 생성한 검색 키워드만 전송되며, 이용자의 목표·현재 상황 원문이나 계정 정보는 전송되지 않습니다.

The Guardian Open Platform
네이버 검색 API
각 언론사 RSS 피드

5. 다른 이용자에게 공개되는 정보

본 서비스의 커뮤니티 기능을 이용할 경우, 다음 정보가 로그인한 다른 이용자에게 공개됩니다.

닉네임
작성한 댓글 내용 및 작성 시각
인사이트 점수

닉네임은 다른 이용자에게 표시되므로, 실명이나 신원을 특정할 수 있는 문구의 사용을 권장하지 않습니다.

이용자의 이메일 주소와 Google 계정 정보는 다른 이용자에게 공개되지 않습니다. 이용자가 입력한 목표 및 현재 상황 텍스트 또한 다른 이용자에게 공개되지 않습니다.

6. 개인정보의 보관 및 파기

이용자의 개인정보는 회원 탈퇴 시까지 보관하며, 탈퇴 시 지체 없이 파기합니다. 읽은 기사 기록은 생성일로부터 7일 후 자동 삭제됩니다. 관련 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.

7. 계정 및 데이터 삭제 요청

이용자는 앱 내 설정 화면을 통해 계정 삭제를 요청할 수 있으며, 아래 연락처로도 삭제를 요청할 수 있습니다. 계정 삭제 시 프로필 정보, 저장한 기사, 메모, 브리핑 기록이 함께 삭제됩니다.

작성한 댓글은 다른 이용자의 대화 맥락 유지를 위해 삭제 후에도 익명 처리된 형태로 남을 수 있습니다.

8. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

자신의 개인정보에 대한 열람 요청
오류가 있는 개인정보의 정정 요청
개인정보의 삭제 요청
개인정보 처리 정지 요청

권리 행사는 앱 내 기능 또는 아래 연락처를 통해 가능합니다.

9. 개인정보의 안전성 확보 조치

이용자 데이터는 Google Cloud Firestore에 저장되며, 전송 구간은 암호화(HTTPS)됩니다. 데이터베이스 접근 권한 규칙(Security Rules)을 통해 본인 외의 접근을 제한합니다. 인증되지 않은 접근으로부터 이용자 데이터를 보호합니다.

10. 아동의 개인정보

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 아동의 개인정보가 수집된 사실이 확인될 경우 지체 없이 삭제합니다.

11. 개인정보처리방침의 변경

본 방침이 변경되는 경우 변경 사항을 본 페이지에 게시하며, 중요한 변경의 경우 앱 내 공지를 통해 안내합니다.
